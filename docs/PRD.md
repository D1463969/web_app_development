# 產品需求文件 (PRD)

## 1. 專案概述
- **專案名稱**：任務管理系統 (To-Do List)
- **專案描述**：一個幫助使用者記錄日常待辦事項、設定優先級並追蹤完成進度的系統。
- **背景與動機**：現代人生活忙碌，常常會忘記重要的待辦事項。本系統旨在提供一個簡單易用的任務管理平台，提升使用者的生活與工作效率。
- **目標用戶**：需要管理個人工作或生活待辦事項的一般使用者、學生或上班族。
- **核心價值主張**：以極簡的介面讓使用者快速新增、管理及追蹤任務狀態，降低認知負擔。

## 2. 功能需求
主要功能列表與使用者故事：

1. **使用者註冊與登入**
   - 作為 **一般使用者**，我希望 **能夠註冊並登入帳號**，以便 **保護我的待辦事項隱私，並在不同裝置上存取**。
2. **新增待辦事項**
   - 作為 **一般使用者**，我希望 **能夠快速新增待辦事項**，以便 **記錄當下想到的任務**。
3. **設定優先級與截止日期**
   - 作為 **一般使用者**，我希望 **能夠為任務設定優先級（高/中/低）與截止日期**，以便 **知道哪些事情需要優先處理**。
4. **編輯與刪除待辦事項**
   - 作為 **一般使用者**，我希望 **能夠修改任務內容或刪除不再需要的任務**，以便 **保持清單的準確性與整潔**。
5. **標記完成狀態與篩選**
   - 作為 **一般使用者**，我希望 **能夠將任務標記為已完成，並依照狀態（全部/未完成/已完成）進行篩選**，以便 **清楚掌握目前的進度**。

## 3. 非功能需求
- **技術限制**：
  - 後端：使用 Python + Flask 框架。
  - 前端：使用 Jinja2 模板引擎與原生 HTML/CSS 渲染頁面。
  - 資料庫：使用 SQLite。
- **效能與安全考量**：
  - 密碼需經過 Hash 處理（如 Werkzeug 的 security 模組）後才能存入資料庫。
  - 防止 SQL Injection 與 XSS 攻擊。
  - 頁面載入時間應小於 1 秒。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (必須有)**：
  - 新增、修改、刪除、查詢任務（CRUD）
  - 任務的狀態切換（未完成/已完成）
- **Should Have (應該有)**：
  - 簡單的使用者註冊與登入
  - 任務截止日期與優先級
- **Nice to Have (可以有)**：
  - 根據狀態或優先級篩選清單
  - 逾期任務提醒（視覺標示）
